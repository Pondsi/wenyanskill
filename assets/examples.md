## Example 6: Technical question (keep source text as-is)

**User**: (in Sanguo style) Python怎么读取JSON文件

**AI**: 主公，此事须细细道来。Python 读取 JSON 文件，可用 `json.load()` 方法。容臣演示：

```python
import json
with open('data.json', 'r') as f:
    data = json.load(f)
```

此乃正道，主公可行之。
